CAMPUS RUN

校园乐跑助手

手机独立运行
三步开始：选路线 → 检查设置 → 开始跑步

首次使用先授予精确位置权限，并在开发者选项选择“校园乐跑助手”为模拟位置应用。路线保存在手机，无需电脑。

1. 选择或规划路线

点击地图添加路径点，拖动调整；选好学校路线后即可使用默认设置。

0 个路径点 · 0 米

手动输入坐标

2. 设置距离与配速

高级设置：速度、圈数和摆动

无限模式会持续运行到手动停止。摆动是路线偏移，不是加速度传感器模拟。

3. 检查并开始

如果学校规定只能在操场上跑，必须按实际操场准确规划路线，并确认符合学校要求。

校园跑步规则参考

示例规则，请以学校要求为准。有效时段：06:00–17:00、19:00–22:00；距离至少 3 公里，最多计入 10 公里；配速 3–10 分钟/公里；每日有效次数最多 1 次。≤3 公里需在 1 小时内完成，>3 且 <10 公里需在 2 小时内完成，包含暂停时间。恰好 10 公里的时长限制请向学校确认。

需要经过乐跑随机分配的 3 个打卡点。本工具不能读取或确认这些打卡点，也不能确认今日有效次数；请在乐跑中核对。

设置里找不到开发者选项？
  1. 打开设置 → 关于手机；部分手机还需进入“软件信息”。
  2. 找到版本号 / Build 号，连续点击约 7 次，直到系统提示已进入开发者模式；如有提示，输入手机锁屏密码。
  3. 返回设置，搜索“开发者选项”并进入。
  4. 找到“选择模拟位置信息应用”，选择“校园乐跑助手”，然后返回本 App。

入口和名称因手机而异。应用只能打开设置，不能自动开启开发者模式或自动选择模拟位置应用。

开发者选项 → 选择模拟位置信息应用 → 校园乐跑助手。首次开始请保持此 App 在前台；跑步启动后可切换到其他 App。若切换 App 或熄屏后停止更新，请在手机应用设置中允许后台运行，并将电池限制设为不限制。

后台运行设置

无小窗运行。先授予精确位置，再按需设置始终允许位置，申请电池优化豁免，并在厂商应用设置允许后台运行和自启动。运行中保留通知，可从通知结束。

仅尝试恢复近期进度，不补算中断期间距离。结束、完成或出错后不恢复；系统强行停止、重启手机或厂商禁止后台时无法保证恢复。
