开始使用

  1. 规划路线

    点击地图添加至少两个点，或导入 GPX / GeoJSON。输入与导出的坐标使用 WGS84。

  2. 先预览，再选择设备

    设置速度和循环次数，选择地图预览检查轨迹。连接真机时，需要完成相应开发者环境配置。

  3. 观察实际状态

    界面只显示服务返回的回放位置和进度。连接失败时会显示原因；停止后请核对设备定位是否恢复。

底图使用高德地图，并在显示时自动处理 GCJ-02 坐标；加载底图会向高德发送所浏览区域的瓦片请求。路线仍以 WGS84 保存，导出文件可备份或分享。
